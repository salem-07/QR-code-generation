# QR Code Generation --- Previous Work

## Overview

This project documents my previous work exploring the idea of generating
QR codes for links. The goal was to create a QR code that can be scanned
with a phone and direct the user to the intended destination.

## Sample Output

The image below is a sample QR code from this work.

![Generated QR Code](qr-code.png)

## What This Demonstrates

-   Familiarity with the QR code generation workflow.
-   Attention to output quality and scanability.
-   Checking the generated code with a mobile device before delivery.

## Notes

-   The QR code image is included in this repository as `qr-code.png`.
-   Scan the code with your phone to check its destination.
-   This README records prior work on the idea; it does not claim that
    this repository contains a complete QR-generation application.

## Possible Improvements

-   Add a small interface where users can enter a URL.
-   Allow downloading the generated QR code as a PNG file.
-   Add validation and test the QR code against the intended URL.
